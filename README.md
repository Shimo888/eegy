An easy EEG signal processing library in Rust

## Unity Installation
You can install this package via the Unity Package Manager (UPM).

1. Open the Package Manager from `Window > Package Manager`
2. Click the `+` button in the top-left corner and select `Add package from git URL...`
3. Enter the following URL and click `Add`:

```text
[https://github.com/Shimo888/eegy.git?path=eegy-unity/Assets/Eegy](https://github.com/Shimo888/eegy.git?path=eegy-unity/Assets/Eegy)
```
